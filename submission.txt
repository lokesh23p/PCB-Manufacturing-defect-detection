**Project Title:**
Real-Time PCB Defect Detection System using YOLOv8 and Raspberry Pi

**Short Description:**
This project presents a real-time PCB defect detection system using a YOLOv8 deep learning model deployed on a Raspberry Pi. A conveyor setup simulates industrial conditions, and images are captured using a mobile device via IP Webcam for defect analysis. The system detects multiple PCB defects and provides labeled outputs indicating defect presence or absence.
